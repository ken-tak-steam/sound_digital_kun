# 音のデジタル化君

3秒の音声で「標本化」「量子化」「符号化」を体験するブラウザ学習アプリです。

## 機能

- 3秒間のマイク録音、サンプル音の利用
- 圧縮の強さをスライダで調整
- 元音声と圧縮後の音声の再生・波形・PCMデータ量の比較
- 標本化・量子化・符号化をタブで切り替えて圧縮前後を比較
- スライダと再生ボタンを画面下に常時表示

## ローカル起動

依存パッケージやビルドは不要です。Python 3 がある環境で以下を実行してください。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザで http://localhost:8000 を開きます。録音にはマイクの許可が必要です。外部に配置する場合は HTTPS を使用してください。

## ファイル構成

- `index.html`: 画面
- `style.css`: 表示とレスポンシブレイアウト
- `app.js`: 録音、音声処理、再生、図示

## データ量と音声処理

圧縮は標本化周波数と量子化ビット数を下げる学習用の非可逆データ削減です。MP3等への変換ではありません。表示値はヘッダーを除いた PCM 音声の理論データ量（標本数 × ビット数 ÷ 8）です。音声は端末内で処理し、サーバーには送信しません。

## 動作確認

```sh
node --check app.js
```

ブラウザではタブ切り替え、スライダの両端、数値と図の連動、元音声・圧縮後音声の再生を確認します。マイク録音は利用するブラウザと実機で確認してください。
